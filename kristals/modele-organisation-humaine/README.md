# Kristal — Modèle des organisations humaines

Kristal polymorphe réutilisable. Les dimensions **rôles**, **tâches**, **ressources**, **droits**, **responsabilités**, **règles**, **décisions**, **interactions** et **couches temporelles** sont modélisées sans réduire une société à un organigramme unique.

Il ne possède pas les faits historiques; le Kristal `qc-pri-us-009` les possède. Le modèle est en construction, **non publié**. Voir `canon/domain/modele.json` et `canon/state.index.json`.

Validation avec l'Authoring Kit : `py -3 tools/kristal.py check .` puis `build-v9` si le contrôle autorise une candidate. Construire n'est pas publier.
