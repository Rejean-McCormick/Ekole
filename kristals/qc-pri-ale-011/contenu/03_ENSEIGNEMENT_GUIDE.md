# 03 — Enseignement explicite et modelage détaillé

**Objectif pour l’élève (English):** “I can plan and write two ordered paragraphs for a reader, with a clear purpose.” **Critère :** *I can show my plan and point to the job of each paragraph.*

## Moment 1 — Read the task, not just the topic

**Teacher says (or screen text):** “Write a guide to new classmates explaining how to choose and return games from the class game shelf.” Ask aloud: “Who reads?” → *new classmates*; “Why write?” → *to explain how to use the shelf*, not “games.” Show two labels **AUDIENCE** and **PURPOSE**. Contrast “games” (topic) with “to explain” (purpose). Check comprehension using a new prompt: “Invite a neighbouring class to a book exchange.” Learner should answer “neighbouring class” and “to invite.”

## Moment 2 — Plan two paragraph jobs

Model a tiny planning grid:

| Before writing | My notes |
|---|---|
| Reader | New classmates |
| Reason | To explain a routine |
| Paragraph 1: What/where? | Low shelf; labelled boxes; choose a game |
| Paragraph 2: What next? | Check pieces; close box; return it |

**Think-aloud:** “The reader cannot return a game before finding it. The order matters. Notes can be short, but the finished sentences must be complete.” Distinguish the grid from the final prose.

## Moment 3 — Compose and revise live

Write P1: “Our class games are on a low shelf beside the reading table. Every box has a picture on the front. You can look at the picture to choose a game.” Point to who “you” means. Draw a paragraph break. Write P2: “After you play, check the pieces. Put every piece in the box and close the lid. Return the game to the shelf so the next student can find it.” Explain why the second paragraph is not simply more information about location.

**Deliberate error:** Replace the first sentence of P2 with “The games are on the low shelf.” Ask: “Does this advance the explanation?” No; it repeats P1. Restore the return step. **Linguistic check:** “Every box have a picture” → “Every box has a picture”; this is feedback on agreement, not a reason to erase the learner’s entire text.

## Moment 4 — Transfer the procedure without the model

Give **different** prompt: “Write to a visiting class to introduce a pretend student-run mini-museum.” Ask learner only: “Who? Why? P1 job? P2 job?” Allow an original plan: P1 welcome and exhibits; P2 how to explore respectfully. Do **not** provide full paragraphs; this leads into G1–G3 in `04_PRATIQUE_ACCOMPAGNEE.md`.

## Exit ticket (formative, not certification)

On a fresh topic “a classroom puzzle corner,” learner labels audience and purpose and states what changes from P1 to P2. **Satisfactory:** “new visitors,” “to explain,” “P1 location/choice,” “P2 tidy up.” **If not:** re-model the mistaken part only. Offer text-to-speech, visible grid and enlarged print; keep English phrase composition as the target skill.
