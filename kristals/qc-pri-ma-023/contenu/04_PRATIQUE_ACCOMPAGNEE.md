# 04 — Pratique accompagnée : trois guidages décroissants

**Règle générale :** donner l'indice seulement après une première tentative; noter si l'indice a été nécessaire. Les figures décrites par sommets sont fermées du dernier au premier.

### G1 — Appui fort : compter des segments

Figures T : (0,0),(3,0),(1,2); R : (0,0),(4,0),(4,2),(0,2); C : cercle centre (0,0), rayon 2.

**Consigne :** classer dans « exactement quatre côtés polygonaux » et « autres figures ». Indices gradués : (1) pointer un côté droit de R; (2) mettre un point sur chaque sommet; (3) suivre chaque segment avec un doigt.

**Corrigé commenté :** R est dans le groupe (quatre segments); T n'y est pas (trois); C n'y est pas (contour courbe, zéro côté polygonal). **Exclusion à formuler :** « C est une figure plane, mais son contour n'est pas composé de côtés droits. » Retirer les trois aides pour G2.

### G2 — Appui partiel : une paire ou deux

Figures Q : (0,0),(5,0),(4,2),(1,2); R : (0,0),(4,0),(4,2),(0,2); I : (0,0),(4,0),(3,3),(0,2).

**Consigne :** ranger dans colonnes « 0 », « exactement 1 », « exactement 2 paires de côtés opposés parallèles » et dire comment tu le sais. **Indice initial :** « Compare seulement AB avec CD, puis BC avec DA; les côtés ne sont pas parallèles juste parce qu'ils ne se touchent pas. » Indice unique de secours : prolonger les côtés au crayon.

**Corrigé :** I → 0; Q → 1 (AB // CD); R → 2 (AB // CD et BC // DA). **Justification de rejet :** I n'entre pas dans la colonne 1, car aucune paire de côtés opposés n'est parallèle. Le prolongement montre des directions qui se croisent. Retirer le rappel « AB/CD » à G3.

### G3 — Faible appui : figure inclinée

Figures K : A(1,1),B(3,3),C(2,4),D(0,2); Q : A(0,0),B(5,0),C(4,2),D(1,2); T : (0,0),(4,0),(1,3).

**Consigne :** dans « quadrilatères avec deux paires de côtés opposés parallèles », classer chaque figure et justifier l'exclusion de Q ou T. Aucune marque sur les côtés ni exemple sous les yeux. Après une tentative erronée : « Vérifie le nombre de côtés et les directions des côtés opposés. »

**Corrigé :** K seul. K = 4 côtés, AB // CD (vecteurs (2,2)/(-2,-2)), BC // DA (vecteurs (-1,1)/(1,-1)); Q n'a qu'une paire, T a trois côtés et ne peut avoir deux paires opposées. **Réponses alternatives :** choisir Q ou T comme cas de non-appartenance est recevable si propriété exacte donnée.

**Retour formatif individualisé :** difficulté en G1 → segments/sommets manipulables; G2 → prolongements; G3 → rotation et stabilité. Une réussite avec indices n'est pas une preuve autonome de maîtrise.
