# 05 — Four autonomous pairs: learner sheet + correction key

**Instructions:** Read each pair of English sentences. For each bold target word, state what it means **in that sentence**, identify a meaningful prefix/suffix and root where possible, and quote a short context clue. No teacher hints or dictionary during the first pass. These are for rehearsal, not formal mastery evidence.

## Student tasks

### A1 — Classroom
1. “The room was **untidy** after the art lesson; markers and paper scraps covered every table.”
2. “Elena showed **kindness** when she welcomed the new student and helped him find his classroom.”

### A2 — Workshop
1. “The group will **restart** the machine after the technician fixes the problem.”
2. “The **dustless** shelf was clean because Priya had wiped every surface with a damp cloth.”

### A3 — Family outing
1. “Our guide **miscounted** the tickets, so she checked again when one person had no ticket.”
2. “The trail was **peaceful**, with only soft wind in the leaves and no noisy traffic.”

### A4 — Making a booklet
1. “Amina made a **readable** sign by writing large, clear letters that people could see from across the room.”
2. “Her brother **disliked** the first design and asked for a completely different one.”

## Teacher correction key (hide from students)

| Pair | Correct meaning in context | Valid word part | Explicit sentence evidence |
|---|---|---|---|
| A1 untidy | not neat/messy | `un- + tidy` | “markers and paper scraps covered every table” |
| A1 kindness | quality/action of being kind | `kind + -ness` | “welcomed ... and helped him” |
| A2 restart | start again | `re- + start` | “after the technician fixes the problem” |
| A2 dustless | without dust | `dust + -less` | “wiped every surface” / “was clean” |
| A3 miscounted | counted incorrectly | `mis- + count + -ed` | “checked again” / “one person had no ticket” |
| A3 peaceful | calm/quiet | `peace + -ful` | “only soft wind ... no noisy traffic” |
| A4 readable | easy/possible to read | `read + -able` | “large, clear letters” / “from across the room” |
| A4 disliked | did not like | `dis- + like + -ed` | “asked for a completely different one” |

**Scoring for learning feedback:** For each target, mark M (correct meaning), P (real morpheme with correct role), and C (accurate context quote); the response is complete only when all are present. Do not require identical dictionary wording. A teacher should revise an unclear prompt before reuse, rather than force an incorrect answer.

**Example of an acceptable complete answer:** “*Restart* means start again. The prefix `re-` means again, and the machine is used after the problem has been fixed.” The exact quotation “after the technician fixes the problem” is even stronger.

**Decision:** If a learner needs a hint, count this as **guided**, not autonomous; use `06_REMEDIATION_ET_TRANSFERT.md`, then retry fresh evidence items after feedback.
