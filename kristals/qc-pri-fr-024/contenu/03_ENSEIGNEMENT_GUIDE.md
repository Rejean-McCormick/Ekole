# 03 — Enseignement modelé | qc-pri-fr-024

**Objectif annoncé à l'élève :** « Après avoir entendu un message complet, je peux raconter ce qui compte vraiment dans mes mots et répondre à des questions qui vérifient ce que j'ai compris. » (`obj-1`, `crit-1`).

## Séquence de modelage (15–20 minutes adaptables)

**1. Annonce et première écoute.** Dire « Je vais écouter tout le message avant de répondre. Je ne cherche pas à retenir chaque mot. » Faire entendre le script M1 de `01_NOTIONS_ET_EXEMPLES.md` une première fois. Demander : « Quel est le sujet? » Sans noter de points, recueillir « on réorganise le coin lecture ».

**2. Deuxième écoute et segmentation.** Faire réentendre M1 avec pauses naturelles. Modéliser ce raisonnement **après** l'écoute : « Je remarque d'abord et ensuite : deux étapes. J'entends une petite pause après l'annonce. Le mot mais annonce une exception. Je ne vais pas inventer de date précise : le message dit demain. » Écrire uniquement les repères **pour enseigner**, pas lors des preuves : *demain / coussins → bac bleu / livres → étagère / albums empruntés → sacs*.

**3. Transformation.** Comparer trois énoncés : A « Les coussins dans le bac bleu, ensuite les livres dans l'étagère; les albums empruntés restent dans les sacs » (fidèle mais sans sujet/temps); B la reformulation modèle M1 (complète); C « Les albums empruntés vont dans le bac bleu » (inexact). Dire pourquoi B est complet, A partiel et C erroné. Faire produire oralement une reformulation différente de B qui conserve sujet, ordre et exception.

**4. Contrôle des questions.** Poser « Quand? Où vont les livres? Que reste dans les sacs? »; pointer les segments **entendus** justifiant les réponses. Insister : une réponse vraisemblable n'est pas une réponse attestée. Refuser une précision que le message ne contient pas.

**5. Transfert immédiat du modelage.** Faire entendre M2 de `01_NOTIONS_ET_EXEMPLES.md` deux fois et appliquer S-A-R-V : (S) club de dessin, (A) bibliothèque aujourd'hui, cahier, fin à 15 h, (R) lieu remplacé et peinture exclue, (V) 3 questions factuelles. Montrer les deux contre-exemples du fichier de notions seulement **après** les tentatives.

## Indices sonores : distinction enseignable

- **Sonore/prosodique :** pause entre deux segments; accentuation de « plutôt »; variation de débit. Peut guider l'attention, mais peut aussi être liée au style de la personne.
- **Verbal entendu :** *d'abord*, *ensuite*, *mais*, *parce que*. Leur signification aide à interpréter l'ordre, l'opposition ou la cause.
- **Contenu sémantique :** « les ciseaux restent dans la classe » est une information explicite; on ne la déduit pas du ton. Enseigner ces trois catégories pour éviter de surinterpréter la voix.

## Question d'arrêt

Demander : « Si je redis toutes les couleurs, mais que je change *ne sort pas* en *sort*, est-ce une bonne reformulation? » **Non** : la négation est centrale. Demander : « Une pause me dit-elle toujours qu'une chose est interdite? » **Non** : il faut écouter les mots. Si réponse erronée, revenir aux contre-exemples de M1/M2 avant G1.

## Trace formative

Conserver dans le dossier de classe uniquement le niveau d'aide nécessaire et l'erreur corrigée (ordre, exception, fait inventé, sujet), sans publier d'enregistrement ni de données personnelles. Les règles de décision de maîtrise figurent dans `../evaluation/GRILLE_MAITRISE.md`.
