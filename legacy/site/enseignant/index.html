Ekole Enseignant

La bibliothèque des corrigés, diagnostics et outils pédagogiques est hébergée hors du site public.

Démarre le serveur local réservé à ta machine :

py -3 tools\serve_enseignant.py --open

Ouvrir l’application enseignant locale ↗

Le serveur t’ouvrira automatiquement une adresse temporaire de session. Il n’est pas conçu pour une classe connectée ni pour une authentification scolaire de production.

Konstellation Light : démo locale ↗ — application indépendante si démarrée.
