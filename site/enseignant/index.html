Atelier des contenus

L’atelier est protégé par une session locale et fonctionne sur un second port. Pour y accéder, utilisez le lien privé « Éditeur » affiché dans le terminal du lanceur Ekole.

Le lanceur doit être démarré sans --sans-editeur. Le mode édition est désactivé par défaut ; pour pouvoir modifier les textes, lancez-le avec --edition.
